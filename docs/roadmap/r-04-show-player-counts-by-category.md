## Objective

Compute and show the total number of players in a session, broken down by category. Whether to extend an existing dashboard or create a new one remains open. The
[driver repository](../../src/server/repository/driver.repository.ts) already provides driver metadata.

## Completed When

Not yet defined. The owner must decide which session players count, how categories are identified, and where the totals appear.
