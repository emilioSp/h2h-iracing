# R-03: Hide traffic during Lone Qualify

## Problem

Traffic warnings can appear during solo qualifying.

## Goal and scope

1. Apply the R-03 session exclusion only to `Lone Qualify`.
2. Update the existing traffic documentation to explain the exclusion.

## Out of scope

1. New exclusions for `Open Qualify`, practice, or race.
2. Changes to traffic detection thresholds, payload shape, other overlays, or SSE connection policy.
3. New dependencies or architecture changes.
