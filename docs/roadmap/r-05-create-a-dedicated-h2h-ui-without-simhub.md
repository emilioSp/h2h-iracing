## Objective

Run discovery for a dedicated H2H UI that removes the need for SimHub. Start from the existing browser dashboards. Decide the UI's scope, how users launch and arrange it,
and the impact on existing SimHub and OBS workflows. This item covers design and planning, not UI implementation.

## Completed When

The owner has approved both an [ADR](../adr/README.md) that records the selected approach, alternatives, reasons, and consequences, and a technical design under `docs/`
that covers user workflows, architecture, integration, compatibility, and an ordered list of implementation tasks.
